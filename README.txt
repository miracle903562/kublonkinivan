# Сайт «Кублонкин Иван»

Это статический сайт-биография без фотографии, оформленный в сдержанном энциклопедическом стиле.

## Файлы
- `index.html` — текст страницы, метаданные для поисковых систем и структура.
- `style.css` — оформление и адаптация для телефонов.

## Как опубликовать бесплатно на GitHub Pages
1. Создайте аккаунт на GitHub, если его ещё нет.
2. Создайте новый публичный репозиторий, например `kublonkin-ivan`.
3. Загрузите `index.html` и `style.css` в корень репозитория.
4. Откройте **Settings → Pages**.
5. В разделе публикации выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
6. После публикации GitHub покажет адрес вида `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/kublonkin-ivan/`.

## Важно перед публикацией
- В `index.html` замените значение `canonical` с `https://YOUR-DOMAIN.example/` на фактический адрес опубликованного сайта. Если сайт размещён в подпапке GitHub Pages, canonical должен включать полный адрес с этой подпапкой.
- Публичная страница будет доступна всем. Убедитесь, что вы действительно хотите публиковать дату рождения, место рождения и сведения о себе.
- Текст о заработке в несколько миллионов рублей обозначен как сведения со слов автора, поскольку независимая проверка не проводилась.
- После публикации можно добавить сайт в Google Search Console и Яндекс Вебмастер и запросить индексирование. Это не гарантирует показ в поиске или конкретную позицию.
- Это независимый персональный сайт, не статья Википедии.
